## 2024-05-18 - [Optimize Navisworks RunSimulation Performance]
**Learning:** Calling `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection(items)` inside a simulation loop like `RunSimulation` is extremely computationally expensive. This adds an O(N) marshalling overhead (from .NET to COM) for every step in the simulation (height descend step), along with repeated executions of `TestsRunTest` even after a collision has already been found. Navisworks COM API wrappers are slow and should not be repetitively invoked unnecessarily in tight loops.
**Action:** When performing item transforms or running clash tests in loops, always cache COM objects like `InwOpState10` and `InwOpSelection` outside the loop and pass them as parameters to helper methods (like `MoveItemsUsingCOM` and `ResetItemsUsingCOM`). Furthermore, break out of loops immediately using early return/break strategies when a collision is found to bypass extra computational overhead from `TestsRunTest`.
