## 2024-06-18 - Navisworks API COM Marshalling Overhead
**Learning:** In Navisworks plugins, continuously converting .NET model selections to COM selections (`ComApiBridge.ToInwOpSelection`) and accessing the internal COM state (`ComApiBridge.State`) inside simulation loops incurs significant repetitive O(N) marshalling overhead that blocks the thread and slows down operations. Additionally, `TestsRunTest` is computationally expensive and should be avoided if a collision has already been detected.
**Action:** Always evaluate and cache `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection` once outside of repetitive operation loops and pass the cached objects to manipulation methods. Always implement early exit strategies (e.g., `break` or `return`) from collision detection loops as soon as a valid collision is confirmed to prevent redundant `TestsRunTest` executions.
