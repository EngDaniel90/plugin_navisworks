## 2024-05-24 - [Performance Improvement: Navisworks COM API Object Caching and Simulation Loop Early Exit]
**Learning:** In Navisworks COM API simulations (`RunSimulation`), creating `InwOpState10` and `InwOpSelection` objects inside the inner move loop causes substantial redundant O(N) marshalling and initialization overhead. Additionally, the clash detection logic (`TestsRunTest`) is computationally expensive and continuing the descend simulation loop after a valid collision has already been found results in unnecessary processing.
**Action:** Always extract and cache `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection(items)` outside simulation loops to reuse them. Implement early `break` logic from both the clash result evaluation and the main descend loops as soon as a `New` or `Active` clash is detected.
