## 2026-05-12 - Early Exit and COM Caching in Navisworks Simulation Loops
**Learning:** In Navisworks collision detection loops, executing `TestsRunTest` is extremely computationally expensive. Without early exit strategies, loops continue unnecessarily even after a collision is found. Additionally, repeatedly accessing COM API bridge properties (e.g., `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection`) inside loops causes severe O(N) marshalling overhead.
**Action:** Always implement early exits (`break` or `return`) as soon as a valid collision is identified to avoid redundant API overhead. Cache `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection` objects once outside of simulation loops and pass them directly to helper methods to eliminate repetitive marshalling overhead.
