## 2024-05-23 - Optimize Simulation Loop with COM Caching and Yielding
**Learning:** In Navisworks `.NET` to `COM` API bridging, repeatedly calling properties like `ComApiBridge.State` or `ComApiBridge.ToInwOpSelection()` inside a tight simulation loop introduces severe `O(N)` marshalling overhead, crippling performance. Furthermore, using `Task.Delay(50)` to force the UI to render the geometry update artificially caps the simulation throughput at 20 ticks per second.
**Action:** Always cache the resulting COM objects (`InwOpState10`, `InwOpSelection`) before entering the `while` loop and pass them to downstream methods (`MoveItemsUsingCOM`, `ResetItemsUsingCOM`). Replace hardcoded `Task.Delay` with `await Task.Yield(); Application.DoEvents();` to maximize simulation speed while ensuring the Navisworks view actually updates for clash testing.
