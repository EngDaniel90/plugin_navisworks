## 2024-05-24 - Optimizing the Navisworks Simulation Loop
 **Learning:** In Navisworks collision detection loops, executing `TestsRunTest` is extremely computationally expensive. In addition, there is a large O(N) marshalling overhead when creating COM objects inside `while` loops. Using hardcoded `Task.Delay` limits throughput when rendering geometry changes, which should be done using `Task.Yield()` and `Application.DoEvents()`.
 **Action:** Always cache `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection` outside of simulation loops, implement early exits (`break`) to stop `TestsRunTest` immediately upon finding a collision, and replace blocking `Task.Delay` with `await Task.Yield()` + `Application.DoEvents()` to maximize throughput while maintaining UI responsiveness.
