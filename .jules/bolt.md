## 2024-05-18 - Navisworks COM API Caching and Loop Optimization
**Learning:** In Navisworks plugins, properties like `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection(items)` have massive overhead because they marshal objects between the .NET API and the older COM API. Calling these inside a simulation loop creates an O(N) performance bottleneck. Additionally, `TestsRunTest` is computationally expensive, and simulation loops should exit immediately once a collision is detected rather than continuing redundant tests.
**Action:** Always cache COM state and selection objects before entering simulation loops, passing them as parameters to helper methods (`MoveItemsUsingCOM`, `ResetItemsUsingCOM`). Implement early exit (`break` or `return`) from collision detection loops immediately after a valid collision is identified.
