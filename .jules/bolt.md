## 2024-05-24 - [Avoid O(N) COM Marshalling inside Navisworks loops & Add Early Exits]
**Learning:** Instantiating `ComApiBridge.State` and calling `ComApiBridge.ToInwOpSelection(items)` inside tight loops like `RunSimulation` is extremely expensive because `ToInwOpSelection` invokes an O(N) operation to marshal the .NET collection to COM memory on every step. Furthermore, checking for collisions without early exits (`break`) means computationally intensive API calls (`TestsRunTest`) are executed unnecessarily.
**Action:** Always cache COM references (`InwOpState10`, `InwOpSelection`) before entering simulation or manipulation loops. Pass these cached objects as arguments to helper methods. Additionally, always implement early exit strategies out of `while` and `foreach` loops as soon as a required condition (like finding a clash) is met.
