## 2024-05-24 - Navisworks COM Iteration and Simulation Exit Strategy
**Learning:** In Navisworks collision detection loops, recreating COM API state and selection objects (`ComApiBridge.State` and `ComApiBridge.ToInwOpSelection`) per-iteration creates severe O(N) marshalling overhead. Furthermore, executing `TestsRunTest` is extremely computationally expensive within step-wise loops, meaning any redundant tests post-collision needlessly freeze the UI thread.
**Action:** Always cache COM bridge objects outside of simulation or iteration loops and pass them directly to helper methods. Always implement explicit early exit strategies (e.g., `break` or `return`) from both inner clash evaluation loops and outer simulation loops as soon as a valid collision is identified to avoid subsequent `TestsRunTest` calls.
