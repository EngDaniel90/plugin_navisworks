## 2024-05-24 - [Navisworks COM API Caching & Early Exit]
**Learning:** In Navisworks plugins, `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection` involve heavy marshalling overhead. Calling these inside high-frequency simulation loops like `RunSimulation` (which loops over height steps and validation) creates severe performance bottlenecks. Also, `TestsRunTest` is extremely computationally expensive.
**Action:** Always cache `ComApi.InwOpState10` and `ComApi.InwOpSelection` outside of simulation loops and pass them as parameters to visual manipulation methods (`MoveItemsUsingCOM`, `ResetItemsUsingCOM`). Implement early exit strategies (`break`) in both validation and simulation loops as soon as a valid clash (`ClashResultStatus.New` or `Active`) is detected to prevent redundant test executions.
