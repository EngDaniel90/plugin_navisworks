## 2024-10-25 - Navisworks COM API Marshalling and Collision Overhead
**Learning:** In Navisworks plugins, executing `TestsRunTest` and calling COM API properties like `ComApiBridge.State` or `ComApiBridge.ToInwOpSelection()` inside tight simulation loops causes extreme computational and marshalling overhead. Navisworks COM interactions scale terribly with O(N) operations when executed repeatedly per step. Additionally, without early exit strategies, collision loops perform redundant operations even after a hard clash is confirmed.
**Action:** Always cache `ComApiBridge.State` and converted COM selections outside of simulation loops. Always implement early exit (`break`) strategies for both inner verification loops and outer simulation loops as soon as a valid collision is detected.
