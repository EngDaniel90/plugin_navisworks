## 2024-05-24 - [Simulation Loop Optimization]
**Learning:** In Navisworks plugins, COM `ObjectFactory` state retrieval and `Selection` conversion via COM marshalling inside simulation loops have O(N) overhead that scales poorly. Furthermore, the `TestsRunTest` collision engine API call is severely performance-limiting and block UI threads, requiring aggressive early exits. Lastly, hardcoded `Task.Delay` limits max throughput arbitrarily, while `Task.Yield()` combined with `Application.DoEvents()` is better for triggering Navisworks redraws without imposing artificial minimum delays.
**Action:** When working on Navisworks plugins, aggressively cache the result of `ComApiBridge.State` and `ComApiBridge.ToInwOpSelection()` outside any simulation loop. Replace hardcoded UI blocking delays with `Task.Yield()` + `Application.DoEvents()`. Implement loop breaking immediately upon the first active clash result found in iterative test loops.
