## 2025-02-20 - [Optimize COM API Objects and Improve Clash Check Performance]
**Learning:** Extracting Navisworks COM API properties `doc.Models` and `doc.GetClash().TestsData` out of iterative loops mitigates repetitive, substantial O(N) marshalling overhead. Navisworks internal loop performance is significantly bottlenecked by redundant API interactions, specifically `TestsRunTest`, so implementing an early exit (`break` or `return`) the moment a valid `ClashResult` is evaluated prevents redundant computation within the simulation framework.
**Action:** Always pre-calculate and cache COM Marshalling state/selections outside Navisworks simulation loops and strictly enforce early exit operations whenever evaluating extensive Navisworks API data collections (e.g., test results).
