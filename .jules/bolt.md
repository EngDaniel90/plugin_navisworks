## 2024-05-24 - Navisworks API COM Overhead and Clash Engine Loop Optimization
**Learning:** In Navisworks collision detection loops, API calls suffer significant marshalling overhead and redundant computation. Specifically, re-fetching `doc.GetClash().TestsData` and re-converting `ModelItemCollection` to COM selection (`ComApiBridge.ToInwOpSelection`) inside animation loops drastically decreases performance. Additionally, the `TestsRunTest` method is extremely computationally expensive.
**Action:** Always cache Navisworks API properties (`TestsData`) and convert/cache COM API states and selections outside of simulation/animation loops. Implement early exit strategies (`break` or `return`) as soon as a valid collision is found to prevent redundant API overhead in subsequent loop iterations.
