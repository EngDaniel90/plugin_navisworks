Manual de Instalação e Uso: Plugins Navisworks

Este guia detalhado irá orientá-lo passo a passo sobre como compilar, instalar e utilizar os plugins Auto Lifting Clash Analysis e Viewpoint Exporter para Autodesk Navisworks Manage 2026.

Nota Importante: Este tutorial assume que você tem o Autodesk Navisworks Manage 2026 instalado em seu computador.

Parte 1: Instalação do Visual Studio Community

Para transformar o código (texto) em um plugin funcional (arquivo .dll), você precisa de um compilador. Usaremos o Visual Studio Community, que é gratuito.

1 Acesse o site oficial da Microsoft para baixar o Visual Studio Community 2022.
2 Execute o instalador (VisualStudioSetup.exe).
3 Durante a instalação, você verá uma tela de "Cargas de Trabalho" (Workloads). É crucial selecionar a opção:
✅ Desenvolvimento para desktop com .NET (.NET Desktop Development)
[Imagem: Tela do instalador do VS mostrando a opção '.NET Desktop Development' marcada]
4 Clique em Instalar e aguarde a conclusão.

Parte 2: Compilando os Plugins

1. Abrindo o Código

1 Baixe os arquivos deste repositório para uma pasta em seu computador (ex: C:\MeusPluginsNavisworks).
2 Abra o Visual Studio 2022.
3 Clique em "Abrir um projeto ou solução" e selecione o arquivo .csproj do plugin que deseja compilar (ex: AutoLiftingClashAnalysis.csproj ou ViewpointExporter.csproj).

2. Verificando Referências

O código precisa saber onde o Navisworks está instalado para funcionar. O projeto está configurado para o caminho padrão:

C:\Program Files\Autodesk\Navisworks Manage 2026\

Se o seu Navisworks estiver instalado em outro local (ou outra versão), você precisará:

  1. No Visual Studio, olhe para o painel "Gerenciador de Soluções" (Solution Explorer) à direita.
  2. Expanda Dependências > Assemblies.
  3. Se houver um ícone de alerta amarelo ⚠️, clique com o botão direito na dependência e selecione Propriedades ou remova e adicione novamente apontando para a pasta correta do seu Navisworks (procure por Autodesk.Navisworks.Api.dll).

3. Compilando (Build)

1 No topo da tela, mude a configuração de Debug para Release (recomendado para uso final).
[Imagem: Barra de ferramentas superior do VS com 'Release' e 'Any CPU' selecionados]
2 Vá no menu Compilação (Build) > Compilar Solução (Build Solution) ou pressione Ctrl + Shift + B.
3 No rodapé, você deverá ver a mensagem: Compilação com êxito.
4 Navegue até a pasta do projeto no Windows Explorer:
...\AutoLiftingClashAnalysis\bin\Release\net8.0-windows\
Lá você encontrará os arquivos .dll gerados (ex: AutoLiftingClashAnalysis.dll).

Parte 3: Instalando no Navisworks

Agora que você tem os arquivos compilados, vamos instalá-los.

1 Feche o Navisworks se estiver aberto.
2 Navegue até a pasta de Plugins do Navisworks. Geralmente fica em um destes locais:
  • C:\ProgramData\Autodesk\Navisworks Manage 2026\Plugins\ (Para todos os usuários)
  • %AppData%\Autodesk Navisworks Manage 2026\Plugins\ (Apenas para seu usuário)
Se a pasta "Plugins" não existir, você pode criá-la.
3 Crie uma pasta para cada plugin dentro do diretório Plugins:
📂 Plugins
  📂 AutoLiftingClashAnalysis
  📂 ViewpointExporter
4 Copie todos os arquivos da pasta de saída do Visual Studio (bin\Release\net8.0-windows\) para as respectivas pastas que você criou.

Parte 4: Como Utilizar

🏗️ Auto Lifting Clash Analysis

Este plugin simula o içamento de módulos e verifica colisões automaticamente.

1 Abra seu modelo no Navisworks.
2 Vá para a aba Add-ins (Complementos) no menu superior. Você verá o botão do plugin.
3 Ao clicar, uma janela abrirá:
  • Pasta de Selection Sets: Selecione a pasta que contém os Sets dos módulos a serem içados.
  • Altura de Içamento: Defina até que altura (em metros) o objeto subirá.
  • Passo de Descida: Define a precisão da simulação (intervalo de verificação).
4 Clique em Iniciar Simulação. O plugin processará o movimento e avisará se houver colisões.

📷 Viewpoint Exporter

Este plugin exporta todas as suas vistas salvas como imagens PNG.

1 Organize suas Saved Viewpoints no Navisworks como desejar.
2 Vá para a aba Add-ins e clique em "Exportar Viewpoints".
3 Uma janela pedirá para você selecionar a Pasta de Destino onde as imagens serão salvas.
4 Após selecionar, aguarde a mensagem de "Concluído". Todas as imagens estarão na pasta escolhida, com nomes limpos e seguros.
